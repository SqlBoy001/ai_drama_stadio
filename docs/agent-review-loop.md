# 独立审核闭环：已实现范围与验收

2026-09-20。当前已落地**剧本审核**及**分镜首帧视觉审核/定向修正**，仍保留人工图片门禁，不是全媒体自动导演。真实剧本生成后由独立上下文的审核角色调用文本模型，修正角色只收到原创作目标、当前剧本及具体问题；模型可以相同，不能宣称模型意见完全独立或保证质量。

## 流程

初稿→初审→通过则自动进入现有视觉资产阶段；不通过则修正1→复审→修正2→复审。最多两次修正、三次审核，共五次额外文本调用。证据不足、格式异常、模型异常、无实质修改、输入超过100000字符、计划预算余量不足时，提前转人工。既有资产/成片人工审核门保留，不把文本通过等同图片或视频通过。

审核逐项覆盖用户方向、人物动机、开头、事件密度与主动性、爽点、伏笔答案和因果、对白与可拍性。问题必须带位置、证据、违反目标、具体修正要求。不得仅返回“建议更精彩”。

## 持久化与接管

agent_review_cycles按run_id+stage唯一保存创作合同、初稿/两次修正版、逐轮意见、调用计数。外部调用前先保存计数；中断不自动重试。并发不能取得第二份额度。重新执行script也不能重置上限或覆盖人工编辑过的当前剧本。对外通过getRun.review_cycles读取。

工作台新增“独立剧本审核”面板，展开各版剧本和证据；HUMAN_REVIEW必须填写判断依据才能放行。人工放行为HUMAN_ACCEPTED，保留原AI结论及approval_requests中的理由，不伪装为AI通过。驳回后可在制作页手动改稿并恢复；不再自动重生。

## 费用与验证边界

- 本轮真实模型调用0。Mock普通任务不伪造语义审核通过；测试通过注入固定响应验证状态机。
- 五次调用是程序硬上限；当前额外5元是计划预留，不是按供应商token账单结算的人民币硬封顶。现有成本面板也采用估算。不能宣称此模块已经实现准确计费或真实模型内容质量认证。
- 图片视觉审核和定向重绘现已接入，参见下节；视频动作/声源自动评审尚未接入。媒体缺少证据时仍交人工，不通过存在性检查冒充语义检查。
- 图像/视频接入前应先拆开现有assets/media的批量生成边界，再为每种素材定义可验证合同和依赖失效范围；不能直接把文本提示词当作实际画面送审。

## 2026-09-20：图片/视频生产边界已拆开

新增独立IMAGE_REVIEW节点，图片生成后停止，逐张对照动作要求人工确认；只有通过后才发起视频/配音。缺图不能放行；剧本、人物、场景、分镜、图片路径改变后旧版本审核失效。视频提交前重复校验，防止绕过。摘要追踪数据库记录，不对本地文件字节做指纹。

驳回图片后，在制作页局部修改并恢复，可重新审核现状，不自动批量重生。没有视觉模型结论时明确HUMAN_REQUIRED。图片自动语义审核及两轮自动局部修复尚未实现。

## 2026-09-20：逐镜视觉审核与局部重绘

需要在AI配置中独立添加 `vision_review`，使用支持多图输入的OpenAI兼容chat/completions模型；不配置则转人工，不尝试文本默认模型。只有新真实图片阶段会执行，历史运行不会自行追加调用。Mock默认不发模型请求；测试使用注入响应。

每镜实际输入：待审首帧、角色ID对应的参考图、场景与道具参考图、分镜/连续性合同。只支持根目录内可解码的静态本地PNG/JPEG/WebP，单图5MB、最多8图；未下载到本地/缺参考/不明确角色列表时人工处理。保存字节指纹，审核期间任一参考或上游变动使结论失效。

独立审核逐项检查人物、动作/道具归属、空间、构图、信息可读性。每镜最多3审2改；整run最多30次附加调用。定向修正带待修原图，创建无分镜/场景绑定的候选任务，只有审核通过才绑定首帧；旧文件保留。失败/不确定/中断不自动重试，已有审核周期不会刷新额度或触发恢复重买。通过仍停在人工图片确认门，不自动进入付费视频。

用户可在独立图片审核面板对照原图与候选、逐项证据，再填写人工放行理由。AI通过与人工接受明确区分。本地没有视觉配置，且本轮真实模型调用0，不能声称已验证模型判断准确率。每次1元只是计划预留，不是账单硬上限。视频动作连贯/音频验收尚未自动化，人工确认之后文件原位改写检测仍待补齐。

最终验证：153后端、18前端、语法、构建、启动与HTTP Mock冒烟通过；浏览器确认三版、两次修正/五次调用、人工理由必填。相关测试包含多图真实请求结构、无文本回退、两轮失败、通过后绑定、手工修改保护、文件内容变化、重入/中断/取消、越界、生产Mock调度和恢复不重复购买。
