# ChatCut 自动剪辑与回传验收

2026-09-21。结论：已批准原始视频/独立音轨的自动粗剪、原生导出、文件回传和人工版本审核闭环通过。验证包含真实Desktop和隔离数据库；不代表《今天重来》或120秒新剧的内容质量通过。

## 已实现

- 从已注册官方Desktop MCP启动传输；读取实际工程和当前操作规范，处理真实JSON文本回执、协议错误/超时。只允许剪辑操作，无模型生成路径。
- 当前批准快照→精确文件/指纹→素材ID→独立时间线、画面/对白/旁白轨→按实际fps放置片段。配音不截断；有配音时压低源声音。保留用户原有时间线。
- 素材和剪辑操作落SQLite断点；重复成功调用复用，不重建。结果不明的远程修改不自动重试。
- 导出入队仅为EXPORT_QUEUED。文件稳定后完整解码、核对时长/720p/画幅，复制到平台存储，保存文件SHA与时间线摘要，进入REVIEW_REQUIRED。
- 工作台展示目标工程、创建剪辑稿并导出、自动轮询回传、播放、下载；本地原合成方式保留。
- 人工审核要求具体依据，批准前重查当前源、时间线和成片字节；审核绑定这版文件。不是只点按钮就把技术成功当作内容成功。
- 采用裁切/顺序/音量等局部修改时，核对来源仍属批准素材，旧输出记录归档、新摘要进入READY，重新导出和审核，旧文件保留。

## 当前限制

- 自动验收范围是批准视频/音频轨。原生字幕、MG图层、附加特效和转场尚未纳入完整版本证据；发现这些内容会阻断自动验收，不能宣称它们已自动支持。
- 导入后，Desktop回读验证ID/类型；本地源指纹不等于Desktop内部副本哈希证明。
- 不确定修改PENDING/UNKNOWN需要对账，目前没有通用一键对账恢复。多实例并发及强制中断恢复仍需扩大测试。
- 当前粗剪按批准镜头时长排列，局部裁切/顺序/音量修改可重新采用；不自动作出成熟导演的节奏判断。
- 完整真实剧情动态与听审未完成；抽帧、音频频率和解码不能代替台词语义/口型/表演审查。当前历史素材内部使用限制保留。
- 新增付费调用0；没有复用已耗尽制作预算，没有公开发布，也没有把测试色块当真实作品。
