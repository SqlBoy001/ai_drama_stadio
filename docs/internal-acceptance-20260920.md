# AI 短剧工作台内部验收 · 2026-09-20

结论：带审核节点的制作工作流通过本轮内部验收，可进入小规模用户试用。不是无人值守成片质量认证，也不是新的两分钟精品成片交付。

## 范围与证据

| 环节 | 已验证能力 | 边界 |
|---|---|---|
| 一句话创作 | 引导问题、保存方案、30–120秒、720p目标、预算门禁；浏览器120秒Mock方案进入剧本审核 | 自然语言写“两分钟”仍需在时长设置确认；Mock为明确标注的占位内容 |
| 剧本 | 独立评审上下文、证据、最多两轮修正、三版保存、人工理由 | 不保证剧本获得关注；没有本轮真实文本质量评测 |
| 资产/分镜 | 人物定妆与分镜方案独立人工确认，图片确认后才生成视频 | 方案阶段仍是人工审核 |
| 图片 | 实际参考图与目标图、多图视觉审核、最多两轮定向候选、通过才替换 | 模型仍可能误判；不确定交人工 |
| 视频 | 实测尺寸/时长/画幅/完整解码，六帧及首帧参考视觉审查；两轮局部修正 | 抽帧不能证明逐帧连贯，完整声音、对白、口型要求人工播放确认 |
| 导出 | 锁定批准的视频版本，前后校验文件SHA256；真实FFmpeg合成后再检查，可播放下载 | 历史成片没有新检查记录时明确标注，不能当新验收通过 |
| 故障/成本 | 调用计数持久化、恢复不重置额度、错误交人工、不默认整批重买 | 人民币为估算预留，不是供应商账单硬封顶 |

无凭据隔离环境执行实际720×1280视频probe、全量解码、抽帧、人工理由审批、锁定版本合成、再验收。浏览器视频时长2秒，播放进度实测前进且无媒体错误；这是测试图案和提示音，不是剧情样片。浏览器新用户120秒方案进入剧本审核；预算不足会停止，调整参考预算后继续。旧侧栏合成状态不同步及历史成片误称已验收已修正。
