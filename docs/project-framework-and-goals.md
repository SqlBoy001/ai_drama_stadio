# 项目框架与设计目标

扫描日期：2026-09-17。依据当前源码、git diff、task_plan.md、progress.md、findings.md；历史验收与本轮验证分开记录。

## 架构与功能

LocalMiniDrama 1.2.8 的增量开发项目，三个独立子项目，无 monorepo 工具；纯 JavaScript。

| 层 | 技术与职责 | 入口 |
|---|---|---|
| 前端 | Vue 3 / Vite / Element Plus / Pinia / Vue Flow；项目、剧集、列表制作、画布、素材库、自由创作、AI 配置、Agent 工作台 | frontweb/src/router/index.js；开发端口 3013 |
| 后端 | Express / better-sqlite3；生成、异步任务、媒体处理、导入导出、编排、审核、费用与质量记录 | backend-node/src/app.js、routes/index.js；默认端口 5679 |
| 桌面 | Electron 28 / electron-builder；封装本地后端与前端 | desktop/main.js |
| 本地数据与媒体 | SQLite、项目 metadata、存储目录、FFmpeg/FFprobe；启动自动迁移 | backend-node/src/db、migrations、tools/ffmpeg |

开发模式前端代理 /api、/static；构建后由后端提供 frontweb/dist。列表与画布共用项目数据，画布布局和工作流分组写入 metadata，不另建业务真源。

业务链路：创意/小说 → 多集剧本 → 角色/场景/道具 → 分镜与提示词 → 参考图/关键帧 → 视频与可选配音 → 合成/质检/导出。支持经典单图、首尾帧、全能参考图模式，以及素材复用、历史媒体、批量工作流。

Agent 层：结构化计划与成本预估 → 剧本审核 → 资产审核 → 媒体生产 → 成片审核 → 导出；支持暂停/恢复/取消/重试、预算拦截和记录持久化。Mock 编排位于 agentWorkbenchService.js，真实编排位于 agentProductionService.js。

## 用户设计目标（从已有记录明确提取）

1. 面向小说爽文、悬疑、系统类漫剧：剧情完整优先，其次是核心动作清晰、人物稳定，再考虑局部动画精度。
2. 自然语言启动，先看计划与成本；通过少数关键审核点掌控自动生产，并可进入制作页人工接管。
3. 本地优先、复用现有技术栈和数据，不引入微服务或重写底座。真实生成会向所选供应商发送必要文本和素材，不能把“本地优先”理解为完全离线。
4. 降本靠按镜头复杂度选模、资产复用、局部重算；完整动态镜头是生产目标，静帧运镜只作明确标识的失败兜底。
5. 项目画风贯穿角色、场景、分镜、视频；人物服装连续，手机剧情信息与人物表情的构图不能物理矛盾。
6. 任务可追踪、故障可恢复、费用可解释；质量问题应阻断或局部修复，避免带错进入下一轮付费步骤。
7. 当前开发以零付费 Mock 验证闭环，最新要求优先于历史真实 API 授权。
