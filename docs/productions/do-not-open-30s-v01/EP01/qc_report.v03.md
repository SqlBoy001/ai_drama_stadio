# 《别开第二次门》30秒样片 v03 验收记录

日期：2026-09-21。成片：backend-node/data/production/do-not-open-30s-v01/do-not-open-30s-v03.mp4。

## 结论
可用于小范围观众测试的有限动态样片，技术检查通过；尚未证明商业吸引力或精品成片标准。不是30秒全动态动画，也不是工作台一键全自动生产验收。本轮使用现有供应商接口生成素材，再以本地 FFmpeg 编排完成。

## 内容与修正
六镜各5秒，依次为未来的自己警告、母亲身份疑点、手动反锁、腕部红痕、门外模仿自己的声音、曾经开门的录音。复用已验证的换手及反锁视频；新增一个 Seedance 2.5 反应镜头、一张腕部参考图、七句 MiniMax 配音。三个镜头采用静图运镜。

首版中文字幕字体缺失，已改用可用中文字体并逐图复核。v02连续两个门锁镜头节奏拖沓，v03把第二镜改为人物听声反应。原版本保留，不增加付费重试。锁具状态使用已验收 lock-v03，广角裁切隐藏不一致的旧锁。红痕、黄色袖口、左手手机在新反应镜头采样检查中保持；人物存在轻微张口，不宣称口型同步通过。

## 验证与证据
- 30.000秒、720×1280、24fps，全片解码通过，无检测到的黑场；final-v03-probe.json、final-v03-scan.log。
- 字幕、片名及AI标识视觉检查：final-v03-contact.jpg。中文可读且无明显溢出。
- 最终音轨解码PCM与已做ASR的版本相同，final-v03-audio-provenance.json；峰值约-2.206dBFS。
- 七句对白均有对应转写内容；混音中“锁好了”被ASR识别成“说好了”，独立干声识别为“鎖好了”。证据final-asr.json、locked-clean-asr.json。保留这项识别歧义，不报告无条件7/7文本匹配。
- ASR、音量扫描和浏览器播放不等于完整主观听审；音色情绪、声音空间感仍需真人观看评价。
- 本轮200后端测试、19前端测试、Vue构建、JS语法检查和隔离Mock启动HTTP冒烟通过。项目无TypeScript/typecheck脚本。构建仍有非阻断大包警告。本轮未新增业务代码。

- v03浏览器实际播放至30秒，ended=true、error=null、720×1280；browser-playback.v03.json。

## 下一步：验证是否值得扩片
先让5至10名目标观众只看一次，不解释故事，再分别回答：
1. 前三秒是否想继续看？在哪一秒想划走？
2. 能否说清主角遇到什么危险？
3. 哪个画面或声音最出戏？
4. 是否想看下一集，最想知道什么？

预先约定方向性门槛：至少70%能复述冲突、至少60%主动表示愿意看下一段，无多人独立指出的同一严重连戏问题。小样本只用于选方向，不证明平台真实留存。未过线先改节奏、信息与声音，不直接批量生成60秒。通过后再固定同一制作方式扩片，并按实际账单核算每个合格镜头成本。
