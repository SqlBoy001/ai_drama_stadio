# EP01 第七次面试
## 本集承诺
通过外部证据与主动选择，打破重复拒绝而失忆的困境。
## 前集衔接
独立试播，无前集依赖。
## 0–3秒
抽出自己字迹的警告纸，直接给出重复面试的异常。
## 场景剧本
SC-001：近未来、日间、封闭面试室。许澄CST-001与面试官CST-002；主角目标是取得工作但不伤害上一位，阻力是规则及面试官。以下是压缩对白后的实际拍摄稿，取代候选梗概的较长对白。


### 0–8秒 / S001
起态：许澄桌左低头伸手。行动：从桌下抽出黄纸，摊到桌面。结果：许澄拿黄纸看向右侧。
CH-001：这字，是我写的。
后期：纸条后期：你已来过六次。别按红键。

### 8–16秒 / S002
起态：两人隔桌坐着。行动：面试官把红键推到桌中央，收手。结果：红键桌中央，许澄没有碰。
CH-002：按下去，明天上班。
CH-001：它会做什么？

### 16–24秒 / S003
起态：面试官看着许澄。行动：面试官指红键后收手。结果：红键仍未按。
CH-002：删除上一位候选人的面试记忆。

### 24–32秒 / S004
起态：许澄手指停在纸边。行动：许澄将亮起的手机扣下。结果：手机扣桌左，纸在主角手中。
CH-001：他不同意呢？
CH-002：他拒绝了。你也要拒绝？
后期：手机房租提醒后期叠加

### 32–40秒 / S005
起态：许澄拿着纸。行动：展开纸内侧，沿正字笔画移动视线。结果：纸摊开，主角紧握纸角。
CH-001：前六次，我都没按？
后期：纸内后期：拒绝以后，下一个被删的是你。

### 40–48秒 / S006
起态：面试官低头看纸。行动：面试官避开许澄视线。结果：面试官垂眼、手离红键。
CH-002：不然，你不会还坐在这里。

### 48–56秒 / S007
起态：许澄靠椅背。行动：许澄抬眼坐直。结果：许澄直视面试官。
CH-001：你们挑的不是能力。
CH-002：是服从。

### 56–64秒 / S008
起态：两人仍隔桌。行动：面试官拿走纸，指向许澄身后的门。结果：面试官持纸，许澄起身。
CH-002：拒绝就出去。下一位到了。

### 64–72秒 / S009
起态：许澄站在门旁。行动：墙上对讲机亮灯，许澄看向面试官。结果：许澄左手抬到对讲机旁。
CH-003：您好，我来面试。
CH-001：能让我问他一句吗？

### 72–80秒 / S010
起态：许澄手在对讲键旁。行动：许澄按住对讲键，面试官从椅边起身。结果：许澄持续按对讲，不触桌上红键。
CH-001：桌上有个红按钮。别碰它。

### 80–88秒 / S011
起态：许澄按对讲，面试官在后。行动：面试官伸手靠近；许澄侧身护住对讲，手不接触。结果：面试官停在一步外。
CH-001：把这句话录下来。忘了也能听见。

### 88–96秒 / S012
起态：面试官停住手。行动：对讲传来录音提示声，面试官收回手。结果：面试官双手垂下看许澄。
CH-002：我第一次，也说过这句话。

### 96–104秒 / S013
起态：许澄保持按对讲。行动：许澄松开对讲转向面试官。结果：许澄与面试官在门边对视。
CH-001：那这次，别替他们关门。

### 104–112秒 / S014
起态：面试官站门旁持纸。行动：面试官按白色开门键；锁响后将纸递回许澄。结果：门打开，许澄接过纸，桌上红键未按。


### 112–120秒 / S015
起态：许澄持纸站门口。行动：门外传来声音；许澄停步翻看纸背，切近景。结果：门保持打开，纸背两种笔迹清晰。
CH-003：这张纸，是我上次塞给你的。
后期：纸背两种笔迹用后期，末秒黑场

## 中段升级

## 最后5秒

## 后集连续性
门打开、纸在许澄手中、门外录音已留、红键未按；下一集从门外人身份继续。
